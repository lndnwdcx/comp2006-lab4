# comp2006-lab4
In order to start the lab.clab.yml file, you must first download the lab4 directory along with the config directory
that has the iptables.rules file in it. Once that is done, you can access it in containerlab. Then you must navigate
to the lab4 directory using the cd command. Once you are in the lab4 directory, you can then deploy lab.clab.yml by
entering the command sudo clab deploy -t lab.clab.yml, and pressing enter. To destroy the lab environment, enter this 
command: sudo clab destroy -t lab.clab.yml, and the lab environment will be destroyed.
